# SoundPad

Консольный саундпад для Windows на C++17: проигрывает звуки по глобальным
горячим клавишам (работают и когда консоль не в фокусе, например в игре),
хранит библиотеку звуков в SQLite и умеет выводить звук сразу на несколько
устройств — например, в виртуальный кабель для микрофона и себе в наушники.

## Возможности

- **База данных** (SQLite): звуки, их громкость, счётчик и время
  проигрываний сохраняются между запусками. Схема версионируется через
  `PRAGMA user_version`.
- **Форматы**: WAV, MP3, FLAC, Ogg Vorbis. Формат определяется по сигнатуре
  файла (а не только по расширению) и проверяется декодером при добавлении.
  Новые форматы добавляются одной записью в `FormatRegistry` (`src/AudioFormats.cpp`).
- **Бинды из конфига** (`soundpad.ini`): глобальные хоткеи через `RegisterHotKey`,
  перечитываются командой `reload` без перезапуска.
- Несколько устройств вывода, наложение звуков или режим «новый обрывает старый»,
  общая громкость и громкость каждого звука отдельно, Unicode-пути и имена.

## Сборка

Нужны CMake ≥ 3.20 и Visual Studio 2019+ (или MinGW-w64). Зависимости
([miniaudio](https://github.com/mackron/miniaudio) и SQLite) CMake скачивает сам.

```bat
cmake -S . -B build
cmake --build build --config Release
build\Release\soundpad.exe
```

Exe собирается со статическим рантаймом и не требует установки чего-либо.

## Использование

```
soundpad.exe [-c путь\к\soundpad.ini]
```

При первом запуске рядом создаётся `soundpad.ini` (пример — `config/soundpad.ini`)
и база `soundpad.db`.

```
> add "C:\Sounds\air horn.mp3" airhorn
+ #1 airhorn  [mp3, 0:02.3]
> import C:\Sounds
> list
id   имя       формат  длит.    громк.  игр   хоткей
1    airhorn   mp3     0:02.3   100%    0     Ctrl+Alt+1
> play airhorn
▶ airhorn
```

| Команда | Описание |
|---|---|
| `add <файл> [имя]` | добавить звук (по умолчанию имя = имя файла) |
| `import <папка>` | добавить все поддерживаемые файлы из папки (рекурсивно) |
| `list` / `ls` | список звуков с хоткеями |
| `info <имя\|id>` | подробности: формат, длительность, каналы, статистика |
| `play <имя\|id>` / `p` | проиграть |
| `stop` / `s` | остановить всё |
| `remove <имя\|id>` / `rm` | удалить из базы (файл на диске не трогается) |
| `rename <имя\|id> <новое>` / `mv` | переименовать |
| `gain <имя\|id> <0-200>` | громкость отдельного звука, % |
| `volume [0-100]` / `vol` | общая громкость |
| `binds` | активные горячие клавиши |
| `reload` | перечитать конфиг и перерегистрировать хоткеи |
| `devices` | устройства вывода |
| `formats` | поддерживаемые форматы |
| `exit` | выход |

Имена с пробелами берите в кавычки. Ссылка `#5` всегда означает id.

## Конфиг

```ini
[settings]
database = soundpad.db        ; путь относительно конфига
outputs  = CABLE Input; default  ; часть имени устройства, через ';'
volume   = 80                 ; 0..100
overlap  = true               ; false — новый звук останавливает предыдущий

[binds]
Ctrl+Alt+1    = airhorn
Ctrl+Alt+2    = "sad trombone"
Ctrl+Alt+3    = #5
Ctrl+Alt+0    = !stop
Ctrl+Alt+Up   = !volume+
Ctrl+Alt+Down = !volume-
```

Модификаторы: `Ctrl`, `Alt`, `Shift`, `Win`. Клавиши: `A`–`Z`, `0`–`9`,
`F1`–`F24`, `Num0`–`Num9`, `NumAdd`, `NumSub`, `NumMul`, `NumDiv`, `NumDecimal`,
`Space`, `Enter`, `Tab`, `Esc`, `Backspace`, `Insert`, `Delete`, `Home`, `End`,
`PageUp`, `PageDown`, `Up`, `Down`, `Left`, `Right`, `Pause`, `-`, `=`, `[`, `]`,
`;`, `'`, `,`, `.`, `/`, `` ` ``, `\`.

Ошибки в конфиге (неизвестная клавиша, дубликат хоткея, хоткей, занятый
другой программой) выводятся с номером строки и не мешают остальным биндам.

### Звук в микрофон (Discord, игры)

Установите [VB-Audio Virtual Cable](https://vb-audio.com/Cable/), укажите
`outputs = CABLE Input; default`, а в Discord/игре выберите микрофоном
`CABLE Output`. Звук пойдёт собеседникам и вам в наушники.

## Структура

```
src/
  main.cpp                 аргументы командной строки
  App.*                    консольные команды, связка модулей
  Database.*               SQLite: схема, миграции, CRUD
  AudioFormats.*           реестр форматов, определение по сигнатуре
  AudioEngine.*            воспроизведение (miniaudio), несколько устройств
  Config.*                 разбор soundpad.ini
  Hotkey.*                 разбор строк "Ctrl+Alt+F1" в virtual-key коды
  HotkeyListener_win.cpp   глобальные хоткеи (RegisterHotKey)
  HotkeyListener_stub.cpp  заглушка для не-Windows сборок (разработка/тесты)
  Console.*                UTF-8 ввод/вывод в консоли Windows
```

Проект также собирается на Linux (без глобальных хоткеев) — удобно для
разработки. Переменная `SOUNDPAD_NULL_AUDIO=1` включает «немое» устройство
вывода для тестов без звуковой карты.
